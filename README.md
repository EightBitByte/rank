# RANK

![](public/preview.png)

Self-hostable ranking webapp for all things media or otherwise.

Rank all of your favorite, movies, games, music, tv, and restaurants. 
Show off your taste for all the world to see.

Deploy to Cloudflare workers or Docker (coming soon), and acquire API keys

## Features:
- All-in-one admin portal + frontend landing page
- Plug n' play free-to-use APIs
- Built-in rate limiting, authentication
